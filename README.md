# first-game1

## נהג אחרון (`last-driver/`)
משחק הישרדות בדפדפן: נוהגים בעיר מלאה זומבים ושורדים כמה שיותר זמן.

- בכל עלייה ברמה בוחרים שדרוג אחד מתוך 3 (15 שדרוגים, 5 שלבים לכל אחד)
- 5 סוגי זומבים ו-3 מיני-בוסים, אחד כל 2 דקות
- מטבעות שנאספים במהלך הסיבוב, וחנות עם 8 סקינים
- טבלת שיאים גלובלית (דרך מסד הנתונים של ה-Claude Artifact)

שליטה: `WASD` / חיצים, `P` להשהיה. בטלפון גוררים אצבע לכיוון הנסיעה.
אפשר לפתוח את `last-driver/index.html` ישירות בדפדפן. במצב הזה הטבלה הגלובלית כבויה והשיא נשמר מקומית.
